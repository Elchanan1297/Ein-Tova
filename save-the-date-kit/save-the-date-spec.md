# אפיון: מצב "Save the date" (נעילת האפליקציה במערכת חיה)

> מסמך לקלוד קוד. **האפליקציה כבר רצה בפרודקשן ויש בה משתמשים.** לכן: (1) קודם סרקו את הקוד הקיים והתאימו שמות ומוסכמות; (2) הכל חייב להיות **כבוי כברירת מחדל**: אחרי הפריסה שום דבר לא משתנה עד שהמנהל מדליק; (3) אפשר לפרוס בלי הפסקת שירות. בתיקייה המצורפת `std/` יש **דמו עובד** (`save-the-date-demo.html`) שהוא המקור האמין לעיצוב ולאנימציה: להעתיק ממנו את ה-SVG וה-CSS.

## 1. מטרה
מסך יחיד, מרשים, שהמנהל מדליק ומכבה ממסך הניהול. כשהוא דלוק **אף אחד לא נכנס לאפליקציה** (כולל משתמשים שכבר מחוברים), רואים רק: לוגו עין טובה, תמונת אבא, הכיתוב "Save the date", תאריך האירוע (לועזי / עברי / שניהם), שעון חול מונפש בצבעי המערכת, וספירה לאחור. מנהל ממשיך לעבוד כרגיל.

## 2. עקרונות לסביבת פרודקשן
1. **בלי שינוי סכמה.** משתמשים בטבלת `Settings` הקיימת: רק שורות חדשות (סעיף 3), seed אידמפוטנטי. אם ל-`Settings` יש מבנה אחר, להתאים.
2. **ברירת מחדל כבוי** (`SaveTheDateEnabled=0`). הפריסה עצמה לא נוגעת באף משתמש.
3. **סדר פריסה:** (א) סקריפט DB, (ב) API, (ג) לקוח. כל שלב לבד לא שובר כלום (לקוח ישן מול API חדש ולהפך).
4. **אכיפה בשרת, לא רק בלקוח.** נעילה שקיימת רק בממשק היא לא נעילה.
5. **החזרה אחורה = מתג אחד** (או סקריפט `UPDATE Settings SET Value='0' ...`). לתעד ב-README.
6. **תאימות לאחור:** לקוח ישן שלא מכיר את השדה החדש מקבל בכל מקרה 423 מהשרת ומציג הודעה כללית (סעיף 6.4).

## 3. הגדרות (שורות ב-`Settings`)
| מפתח | ערך | משמעות |
|---|---|---|
| `SaveTheDateEnabled` | `0`/`1` | המתג הראשי |
| `SaveTheDateEventAt` | ISO 8601 עם אזור, למשל `2027-01-14T19:00:00+02:00` | מועד האירוע. מומלץ לשמור כ-UTC ולהציג ב-`Asia/Jerusalem` |
| `SaveTheDateDisplay` | `gregorian` / `hebrew` / `both` | באיזה תאריך להציג |
| `SaveTheDateHebrewText` | טקסט חופשי, אופציונלי | דריסה ידנית של התאריך העברי (למשל כשהאירוע אחרי השקיעה) |
| `SaveTheDateAfterNightfall` | `0`/`1` | מוסיף יום עברי (האירוע בערב, ואז התאריך העברי הוא של היום הבא) |
| `SaveTheDateHeadline` | טקסט, ברירת מחדל `Save the date` | הכותרת הגדולה |
| `SaveTheDateSubline` | טקסט, ברירת מחדל `70 · עין טובה` | שורה קטנה מעל הכותרת |
| `SaveTheDateLocation` | טקסט, אופציונלי | מקום (שורה מתחת לשעה, אם מלא) |
| `SaveTheDateShowCountdown` | `0`/`1` | ספירה לאחור (ימים/שעות/דקות/שניות) |
| `SaveTheDateAutoOpenAt` | ISO, אופציונלי | **פתיחה אוטומטית**: מרגע זה המסך מפסיק לנעול גם אם המתג דלוק (שימושי: האפליקציה נפתחת לבד בתחילת האירוע) |

כלל הנעילה בשרת (פונקציה `fn_IsLocked`, או שווה ערך): נעול אם `Enabled=1` **וגם** (`AutoOpenAt` ריק או עתידי).

## 4. API
### 4.1 `GET /api/config` (קיים, פומבי)
מוסיפים אובייקט `saveTheDate`. **שדות קיימים לא משתנים** (לקוחות ישנים ממשיכים לעבוד):
```json
"saveTheDate": {
  "locked": true,
  "eventAt": "2027-01-14T19:00:00+02:00",
  "display": "both",
  "hebrewText": "",
  "afterNightfall": true,
  "headline": "Save the date",
  "subline": "70 · עין טובה",
  "location": "",
  "showCountdown": true,
  "serverNow": "2026-11-11T16:51:00Z"
}
```
כש-`locked=false` מחזירים רק `{ "locked": false }`. `serverNow` משמש לספירה לאחור מדויקת גם כשהשעון במכשיר לא נכון.
כותרות: `Cache-Control: no-store`.

### 4.2 נעילה בשרת (Middleware)
Middleware ראשון ב-pipeline (אחרי CORS). כשנעול:
- חוסם עם **`423 Locked`** וגוף `{ "code": "SaveTheDate" }` את **כל** `/api/*` **חוץ מ**: `/api/config`, `/api/health` (אם קיים), `/api/admin/**` (ממשיך לדרוש הרשאת מנהל כרגיל, כולל כניסת המנהל), וה-hub של הנעילה (4.4).
- חוסם גם `login/code`, `login/phone`, `game/*`, `leaderboard`, `photos/*` וכל נקודה פומבית אחרת.
- JWT של משתמשים שכבר מחוברים אינו מועיל בזמן הנעילה.
- מנהל מזוהה בדיוק כמו היום (אותו מנגנון). לא ליצור מנגנון הרשאות חדש.
בדיקת הנעילה קוראת ל-`Settings` דרך מטמון בזיכרון של עד 5 שניות (לא שאילתה לכל בקשה) עם ביטול מטמון מיידי כשהמנהל משנה.

### 4.3 ניהול
- `GET /api/admin/save-the-date` מחזיר את כל ההגדרות (כולל מצב נעילה בפועל אחרי `AutoOpenAt`).
- `PUT /api/admin/save-the-date` מקבל את כל השדות מסעיף 3, מאמת (תאריך תקין, `display` מהרשימה, אורך טקסטים עד 120), שומר ב-`Settings` בפרוצדורה אחת **בטרנזקציה**, כותב ל-`AdminAudit` מי שינה ומה, ומנקה את מטמון הנעילה.
- אין צורך בנקודת "תצוגה מקדימה" בשרת; התצוגה המקדימה בלקוח (6.5).

### 4.4 עדכון חי (SignalR)
Hub קיים או חדש (`/hubs/state`, פתוח גם כשנעול, **בלי** אימות). אירוע `LockChanged(locked)` נשלח לכולם בשינוי מתג או בפתיחה האוטומטית (טיימר רקע בשרת שמפעיל את האירוע ב-`AutoOpenAt`). הלקוח גם עושה **polling** ל-`/api/config` כל 60 שניות ובחזרה מרקע (`visibilitychange`), כגיבוי.

## 5. מסך הניהול (מסך חדש בתוך אזור המנהל הקיים)
כותרת "Save the date" ובו:
1. **מתג ראשי** גדול "נעילת האפליקציה". הדלקה/כיבוי דורשים **דיאלוג אישור** מפורש ("האפליקציה תינעל לכל המשתמשים, כולל מחוברים" / "האפליקציה תיפתח לכולם").
2. **תאריך ושעה:** בורר תאריך ושעה (אזור זמן ישראל). מתחתיו, בזמן אמת, **תצוגה של שני התאריכים** (לועזי ועברי) כדי שהמנהל יראה בדיוק מה ייכתב.
3. **בחירת תצוגה:** שלוש אפשרויות (לועזי / עברי / שניהם).
4. **תאריך עברי:** חישוב אוטומטי, מתג "האירוע אחרי השקיעה" (מוסיף יום עברי), ושדה "דריסה ידנית" לנוסח חופשי.
5. **כותרת, שורה עליונה, מקום:** שדות טקסט עם ברירות מחדל.
6. **ספירה לאחור:** מתג.
7. **פתיחה אוטומטית:** מתג ובורר תאריך ושעה, עם הסבר קצר.
8. **תצוגה מקדימה:** כפתור "תצוגה מקדימה" שפותח את המסך ממש כפי שהמשתמשים יראו, בלי להדליק נעילה.
9. **מצב נוכחי:** תג בולט "נעול / פתוח" וגם באנר קבוע בראש האפליקציה למנהל כשהמצב נעול: "מצב Save the date פעיל (רק מנהלים נכנסים)".
כל טקסט בעברית ו-RTL; שגיאות שמירה מוצגות בבירור.

## 6. הלקוח (Angular)
### 6.1 טעינה ושער
- בעליית האפליקציה (`APP_INITIALIZER` או ה-resolver הקיים) טוענים את `/api/config` **ללא מטמון**. אם `saveTheDate.locked` ואין מנהל מחובר: כל ניווט מנותב אל `/save-the-date` (guard ברמת השורש, `canActivate`/`canMatch`), כולל קישורים עמוקים וקישורי כניסה עם קוד.
- המסך מוסתר מהתפריט התחתון, ואין בו שום דרך להתחבר או לנווט. כפתור "אחורה" בדפדפן נשאר על אותו מסך.
- אם נתקלים ב-`423` מכל קריאת API (לקוח שנפתח לפני הנעילה): לנתב מיד לאותו מסך.
- כשחוזרים ל-`locked=false` (SignalR/polling): ניווט אוטומטי למסך הכניסה הרגיל, בלי רענון ידני.
- מנהל מחובר לא מנותב (רואה את האפליקציה עם הבאנר).

### 6.2 Service Worker / PWA (קריטי, כי זו אפליקציה מותקנת)
- ב-`ngsw-config.json` להוציא את `/api/config` ואת ה-hub מכל מטמון (`dataGroups` עם `strategy: freshness` ו-`maxAge: 0`, או החרגה מלאה).
- מסך ה-`/save-the-date` נטען מתוך אותו bundle (לא נתיב נפרד), כך שהוא עובד גם בלי רשת.
- **לא להסתמך על שמירת מצב נעילה מקומית כדי לפתוח**: אם `config` לא נטען, מציגים את המצב האחרון הידוע רק כדי להמשיך להציג מסך נעילה; פתיחה דורשת תשובה חיובית מהשרת.
- אחרי הפריסה להבטיח שמשתמשים עם גרסה ישנה מקבלים את העדכון (`SwUpdate.checkForUpdate` בעליית האפליקציה והצעה לרענון). ובינתיים ה-423 מהשרת מכסה אותם.

### 6.3 רכיב `SaveTheDateScreenComponent`
Standalone, `OnPush`, Signals. קלט: אובייקט ה-`saveTheDate` מה-config. פלט: אין.
**העיצוב המדויק בדמו.** סדר אנכי (טלפון): לוגו עין (116px) → תמונת אבא בקשת עם טבעת זהב וזוהר (176×204) → שורה עליונה → **Save the date** (Frank Ruhl 900, מדורג זהב) → תאריך (Frank Ruhl 700, 26px) + לועזי קטן + "בשעה HH:MM" בזהב → שעון חול → ספירה לאחור בכרטיסי זכוכית → "נתראה בקרוב". עד 700px גובה: הכל מצטמצם (בדמו כבר מוגדר). רקע: כחול כהה עם הילה כחולה למעלה, זוהר זהב מימין-למטה, קווי גל זהובים, 4 ניצוצות עולים.
כניסה מדורגת בקפיצה עדינה (`cubic-bezier(.34,1.5,.5,1)`), הברק על התמונה, מתחלפים כל 5 שניות.
**תמונת אבא:** `father-bust.png` מהנכסים הקיימים (אותו קובץ כמו בכרטיסי הברכות).
**לוגו:** גרסת הרקע הכהה.

### 6.4 שעון החול (המפרט המלא בדמו)
- SVG אחד (`viewBox 0 0 120 190`): שני פקקים זהובים, זכוכית שקופה עם הברק לבן, חול בגרדיאנט הזהב של המותג, "זרם" דק מקווקו שנע.
- מחזור של **9 שניות בלולאה:** 0–72% החול יורד (העליון מצטמצם והתחתון מתמלא, בלי קפיצות), 78–92% **השעון מסתובב 180°** בקפיצה, ובסוף המחזור המצב זהה להתחלה, כך שהלולאה חלקה.
- הכל ב-CSS בלבד (טרנספורמציות ו-opacity), בלי JS ובלי ספריות. `will-change: transform` על ה-SVG.
- `prefers-reduced-motion`: ללא אנימציה, חול באמצע, בלי זרם.
- `aria-hidden="true"` על השעון; הכותרת והתאריך הם הטקסט הנגיש.

### 6.5 תאריך עברי
- ספרייה מומלצת: **`@hebcal/core`**: `HDate` ו-`renderGematriya()`, ללא ניקוד, בפורמט "ו׳ בשבט תשפ״ז". הדמו משתמש בפונקציה קטנה רק להדגמה ואינו מחליף את הספרייה.
- חישוב לפי אזור הזמן `Asia/Jerusalem`. כש-`afterNightfall=1` מוסיפים יום עברי אחד.
- שגיאת חישוב או טקסט דריסה ב-`hebrewText` מנצחים.
- לועזי: `Intl.DateTimeFormat('he-IL', { timeZone: 'Asia/Jerusalem', ... })` (כמו בדמו).
- תצוגה: `gregorian` מראה רק לועזי; `hebrew` רק עברי; `both` את העברי כשורה ראשית ואת הלועזי מתחתיו.

### 6.6 ספירה לאחור
מבוססת `serverNow` שמתקבל בעת הטעינה (מחשבים הפרש מול `Date.now()` פעם אחת ומתקנים). מתעדכנת פעם בשנייה, **מחוץ ל-Angular zone** (`runOutsideAngular`) ועם `Signal`. כשהזמן עבר: מציגים "היום!" במקום כרטיסי הספירה.

### 6.7 תצוגה מקדימה למנהל
נתיב `/admin/save-the-date/preview` שמרנדר את אותו רכיב עם הערכים שבטופס (גם לפני שמירה), ב-iframe-פריים בגודל טלפון או במסך מלא. לא משנה שום דבר בשרת.

## 7. מצגת ומסך גדול
אם קיים מסך מצגת (SignalR): בזמן נעילה הוא ממשיך לעבוד (מנהל מחובר), ואין לו שינוי חובה. אופציה: במצב "מסך גדול" להציג את אותו רכיב במסך מלא (`?mode=display`). לא בהכרח לשלב א׳.

## 8. נגישות ו-i18n
כל הטקסט בעברית ו-RTL, חוץ מהכותרת הגדולה (ברירת מחדל באנגלית, `dir="ltr"`, ניתנת לעריכה לכל טקסט). `role="main"`, `aria-label`, ניגודיות AA (טקסט בהיר על כחול כהה). כפתורי המנהל נגישים במקלדת.

## 9. אבטחה
- הנעילה נאכפת בשרת (423), לא ניתנת לעקיפה על ידי ידיעת כתובות API.
- נקודות הניהול דורשות את הרשאת המנהל הקיימת. כל שינוי נרשם ב-`AdminAudit`.
- שדות הטקסט מקודדים בעת הצגה (בלי `innerHTML` עם קלט מנהל).
- אין חשיפה של שום מידע מעבר לשדות שבסעיף 4.1 (בלי רשימות משתמשים וכדומה).

## 10. שלבי מימוש מומלצים (כל אחד נפרס לבד)
1. סקריפט DB: seed ההגדרות (כבוי) + שינוי `usp_GetPublicConfig` להחזרת `saveTheDate` (בלי לשבור שדות קיימים).
2. API: Middleware הנעילה + נקודות הניהול + Hub, **כבוי**, עם בדיקות.
3. לקוח: הרכיב והמסך והשער (עדיין כבוי, אפשר לבדוק עם תצוגה מקדימה).
4. מסך ניהול.
5. בדיקה בסביבת בדיקות/סטייג׳ינג, ורק אז הדלקה בפרודקשן בשעה שקטה.

## 11. קריטריוני קבלה
- אחרי פריסה עם המתג כבוי אין שום שינוי למשתמשים קיימים (בדיקת רגרסיה על כניסה, משחק, לוח תוצאות).
- הדלקה: משתמש שפתוח באפליקציה מועבר למסך Save the date תוך 5 שניות בלי רענון, וקריאת API ישירה מחזירה 423.
- כיבוי: המשתמשים חוזרים לאפליקציה תוך 5 שניות (SignalR) או 60 שניות (polling).
- מנהל מחובר ממשיך לעבוד עם באנר, ולא מנותב.
- `AutoOpenAt` פותח את האפליקציה לבד בזמן שנקבע.
- התאריך העברי נכון כולל מקרה "אחרי שקיעה", ודריסה ידנית מנצחת.
- שעון החול נע חלק ב-60fps בטלפון בינוני, ללא קפיצה בסוף המחזור. עם `prefers-reduced-motion` הוא סטטי.
- ב-PWA מותקן (iOS ואנדרואיד), אחרי ההדלקה אין גרסה ישנה שנתקעת בפתוח; ה-config לא נשמר במטמון.
- מסך שנפתח בלי רשת מציג את המסך האחרון הידוע ולא פותח את האפליקציה.
- כל הטקסטים בעברית, RTL, וללא ספינר גנרי (בטעינה הראשונית משתמשים בספינר העין).

## 12. תרחישי בדיקה
